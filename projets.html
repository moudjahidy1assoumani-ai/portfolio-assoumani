Pipeline Data & IA en Production

Data / IA
Description

Conception d'une application web décisionnelle automatisée réalisant la collecte, l'analyse sémantique et la synthèse de données textuelles complexes.

Architecture & Réalisations
  • Data Engineering : Extraction de contenus web en temps réel (Scraping) via Requests & BeautifulSoup4.
  • Data Analytics (NLP) : Développement d'un algorithme déterministe de notation lexicale pour l'analyse de sentiments en français.
  • Génie IA (LLM) : Interconnexion asynchrone par requêtes HTTP POST (API REST) avec le modèle open-source open-mistral-7b de Mistral AI.
  • Data Viz : Restitution dynamique des indicateurs clés (KPI) et graphiques sur un dashboard Streamlit avec Matplotlib.

Undercover FR
Jeu Web Applicatif Multijoueur

Full-Stack
Description

Développement intégral d'une application web de jeu multijoueur synchrone, axée sur une expérience utilisateur fluide et une synchronisation temps réel.

Spécifications techniques
  • Frontend : Architecture modulaire en Vanilla JS (ES Modules) propulsée par le bundler Vite et stylisée avec Tailwind CSS.
  • Backend-as-a-Service : Intégration de Firebase (Realtime Database & Anonymous Authentication) pour la persistance des salons.
  • Logique métier : Algorithmes complexes de distribution équitable des rôles et gestion temps réel du cycle de vie des sessions de jeu.
  • Déploiement : Pipeline d'intégration et déploiement continus (CI/CD) vers la plateforme Cloud Vercel.
